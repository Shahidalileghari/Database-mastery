# Exercises

Try the challenge set after running the ecommerce schema and seed scripts.

Recommended workflow:
1. Write the query without looking up a solution.
2. Test edge cases, especially missing relationships, duplicates, and `NULL`.
3. Inspect the result and explain why each row appears.
4. Consider correctness before performance.
5. For optimization tasks, capture an `EXPLAIN (ANALYZE, BUFFERS)` plan before and after changes.
