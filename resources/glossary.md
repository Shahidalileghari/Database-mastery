# Database Glossary

- **ACID:** Atomicity, Consistency, Isolation, Durability.
- **Anomaly:** Unexpected behavior caused by data redundancy or concurrent operations.
- **CTE:** Common Table Expression, introduced with `WITH`.
- **DDL:** Data Definition Language.
- **DML:** Data Manipulation Language.
- **Foreign key:** Constraint connecting a row to a referenced key.
- **Index:** Auxiliary structure that can speed up access at a storage and write-maintenance cost.
- **Isolation level:** Defines visibility and concurrency guarantees between transactions.
- **Migration:** Versioned, repeatable schema or data change.
- **Normalization:** Structuring relations to reduce redundancy and modification anomalies.
- **OLAP:** Online Analytical Processing.
- **OLTP:** Online Transaction Processing.
- **Query plan:** The optimizer's chosen execution strategy.
- **Referential integrity:** Guarantee that references remain valid according to constraints.
- **Sargable predicate:** Predicate that can be used effectively by an index access path.
- **Window function:** Function that computes across related rows without collapsing them into one row per group.
